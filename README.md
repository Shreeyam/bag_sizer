# Messenger Bag Strap Visualizer

This is a simple web application to visualize the placement of straps on a messenger bag.

## Features

-   **Dynamic Visualization**: See changes in real-time as you adjust sliders.
-   **Adjustable Dimensions**:
    -   Bag Length ($L$)
    -   Bag Height ($h$)
    -   Strap Width ($w$)
    -   Datum Offset (% of Bag Length from center)
-   **Alignment Toggles**: Choose how the straps align relative to the datum lines (Inside, Middle, Outside).

## How to Use

1.  Open `index.html` in your web browser.
2.  Use the sliders to adjust the dimensions.
3.  Use the radio buttons to change the strap alignment.

## Deployment to GitHub Pages

1.  Push this repository to GitHub.
2.  Go to the repository **Settings**.
3.  Navigate to the **Pages** section (usually under "Code and automation").
4.  Under **Source**, select `Deploy from a branch`.
5.  Select the `main` (or `master`) branch and the `/ (root)` folder.
6.  Click **Save**.
7.  Wait a few minutes, and your site will be live at `https://<username>.github.io/<repository-name>/`.
